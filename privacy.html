プライバシーポリシー

取得するデータと目的

チャンネル運営者の同意を得て、YouTube Data APIから対象チャンネルの識別情報と、公開済み・保留中のコメントや返信を取得します。コメントの識別子、投稿者のチャンネル識別子、投稿・更新時刻、公開状態は、新着・重複の確認と運営者自身の投稿の区別に使います。新着コメントと必要な親コメントの本文は、コメント確認のために使います。

処理・保存・共有

コメント本文は、運営者のPC上で動くGemmaとQwenが処理します。本文をファイルや実行ログに保存したり、このサイトや外部のAIサービスに送信したりする機能はありません。実行日時、件数、エラーの種類、APIの利用状況をPCに保存します。重複防止用のコメント識別子は鍵付きハッシュに変換し、確認済みの範囲から外れたものは削除します。OAuthの認証情報はWindowsのユーザー単位の暗号化機能で保管します。

Googleから取得したデータを販売したり、広告やモデルの学習に使ったりすることはありません。Google APIから受け取る情報の利用と移転は、限定利用の要件を含む Google API Services User Data Policy に従います。Googleによるデータの取り扱いは、Googleのプライバシーポリシーをご覧ください。

アクセスの取り消しと削除

認証した運営者は、Googleアカウントの接続管理でアプリのアクセスを取り消せます。ツールがPCに保存したデータについては、運営者に削除を依頼できます。YouTube上の投稿の削除はYouTubeで行います。

お問い合わせ

データの取り扱いや削除については、てんえさ【渓流調査ch】の運営者にご連絡ください。
